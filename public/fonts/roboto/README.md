# Roboto

Variable font, upright, weights 100–900. Latin, Latin Extended and Vietnamese subsets are self-hosted in this directory.

Downloaded from Google's stylesheet on 2026-10-15:
https://fonts.googleapis.com/css2?family=Roboto:wght@100..900&display=swap

Files come from https://fonts.gstatic.com/s/roboto/v51/.
License: OFL.txt, downloaded from https://github.com/google/fonts/blob/main/ofl/roboto/OFL.txt.

The web app loads these local files; Google Fonts is not contacted at runtime.
